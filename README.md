# DevOps CI/CD Demo: Python service in Docker

A small FastAPI service that is tested, packaged as a Docker image, and run as a container by a GitHub Actions pipeline.

## Endpoints
- `GET /` returns a welcome message.
- `GET /health` returns `{"status": "ok"}`.
- `GET /docs` shows the interactive API page (generated by FastAPI).

## Project files
| File | Purpose |
|---|---|
| `app/main.py` | The service: defines the endpoints. |
| `tests/test_main.py` | Automated tests for both endpoints. |
| `requirements.txt` | Libraries the service needs to run. |
| `requirements-dev.txt` | Libraries needed for testing (adds pytest and httpx). |
| `Dockerfile` | Steps to package the service into a Docker image. |
| `.github/workflows/ci-cd.yml` | The pipeline: test, build, deploy. |

## Pipeline stages
1. **Test:** installs dependencies and runs pytest. Failing tests stop the pipeline.
2. **Build:** builds the Docker image and pushes it to GitHub Container Registry (GHCR), tagged `latest`.
3. **Deploy:** pulls the image from GHCR, runs it as a container on the GitHub Actions runner, and checks `/health` until it responds.

## Run it locally
```bash
pip install -r requirements-dev.txt
pytest
uvicorn app.main:app --reload

docker build -t demo-service .
docker run -p 8000:8000 demo-service
curl http://localhost:8000/health
```
